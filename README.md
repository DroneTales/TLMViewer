# Spektrum Telemetry Log Viewer

A free hobby project designed to view, analyze, and parse telemetry logs generated by SpektrumRC transmitters. 

For more details, user guides, and official releases, visit the website: [www.tlmviewer.com](https://www.tlmviewer.com)
